# Dragon Brawl

A 3D fighting game that runs in the browser on iPhone and PC.

## Play

**[Play Dragon Brawl](https://imatination.github.io/Dragon-Brawl/)**

On iPhone, open the link in Safari, tap Share, then **Add to Home Screen** to play it full screen.

## Progress

Unlocked fighters and wins are saved in the browser on each device.
